せどり管理（iOS アプリ）／ 最終更新 2026年11月2日

帳簿の中身（仕入れ・販売・経費・商品の写真）は、お使いの端末の中にだけ保存されます。 開発者がその内容を見ることはできません。

1. 端末に保存されるもの

次の情報は端末内（IndexedDB）にのみ保存され、サーバーへ送信されません。

  • 商品・仕入れ・販売・在庫の記録
  • 経費、固定資産、梱包資材の記録
  • 販路・仕入先・配送方法・支払方法などの設定
  • 撮影したレシートや商品の写真
  • Amazon 連携を設定した場合の接続情報

アカウント登録やログインはありません。バックアップはご自身で書き出していただく形です。

2. 外部に送信されるもの

バーコードを読み取ったとき

商品名を調べるために、読み取った JAN コード（数字）を次のサービスへ送ります。 氏名や帳簿の内容など、あなたを特定できる情報は送りません。

  • Yahoo!ショッピング（ヤフー株式会社）— 商品名と価格の目安
  • openBD — 書籍の書名・著者・出版社
  • 楽天市場（設定でアプリIDを入れた場合のみ）

Amazon 連携を設定した場合

ご自身で接続情報を入力したときに限り、Amazon の Selling Partner API へ接続して 注文・手数料・在庫を取得します。接続情報は端末内にのみ保存されます。

3. 広告について

本アプリは、Unity LevelPlay（ironSource Mobile Ltd.／Unity Technologies）を通じて広告を表示します。 広告の配信のために、広告の配信事業者が端末の情報（機種、OS のバージョン、言語・地域の設定、IP アドレスなど）や 広告の表示・操作に関する情報を取得することがあります。

  • パーソナライズ広告は使用しません。広告は非パーソナライズ配信に限定しています （配信事業者には、個人データの利用に同意していないもの・個人情報の販売を拒否したものとして伝えています）。
  • 他社のアプリやサイトをまたいだ追跡（トラッキング）は行いません。 そのため、追跡許可を求めるダイアログも表示しません。広告識別子（IDFA）は使いません。
  • 広告の配信事業者：ironSource Mobile Ltd.（Unity Technologies のグループ会社。Unity LevelPlay・ironSource Ads）、 Unity Technologies（Unity Ads）。情報の取り扱いは Unity のプライバシーポリシー（ゲーム・アプリの利用者向け） をご確認ください。

App 内課金「広告を消す」（440円・買い切り）をご購入いただくと、広告の表示と、 それに伴う情報の取得は行われなくなります。

4. カメラと写真

バーコードの読み取り、レシートや商品の撮影のためにカメラと写真ライブラリを使います。 撮影した画像は端末内にのみ保存され、外部へ送信されません。 レシートの文字認識も端末内で行います。許可しなくても、手入力ですべての機能を利用できます。

5. 購入について

App 内課金の決済は Apple が行います。開発者がクレジットカード番号などの決済情報を 受け取ることはありません。

6. 第三者への提供

上記以外に、利用者の情報を第三者へ提供・販売することはありません。 法令に基づく開示請求があった場合を除きます。

7. お問い合わせ

ご不明な点は サポートページ の窓口へご連絡ください。
